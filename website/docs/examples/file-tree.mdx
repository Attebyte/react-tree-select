# File tree

`CustomCheckComponent` replaces each checkbox with a folder or file icon, and `CustomExpandIconComponent` hides the arrow. Click a folder to open it, and click a file to select it. Selected files turn blue, and folders with some selected files turn orange.

<LiveExample source={CustomCheckExampleSource} title='CustomCheckExample.tsx'>
  <CustomCheckExample />
</LiveExample>

The custom check component receives `checked` (`true`, `false` or `null` for mixed), `expanded` and `disabled`, so it can show any state. Keyboard users can still select files with <kbd>Space</kbd>, because the tree item, not the icon, holds the checked state.
