# Custom expand icon

`CustomExpandIconComponent` replaces the arrow with a plus that turns into a minus. The icon receives `show` (true for nodes with children) and `expanded`.

<LiveExample source={CustomIconExampleSource} title='CustomIconExample.tsx'>
  <CustomIconExample />
</LiveExample>

Mark decorative icons with `aria-hidden`: the tree item already tells screen readers whether it is expanded.
