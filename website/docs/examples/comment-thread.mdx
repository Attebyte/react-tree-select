# Comment thread

`CustomNodeComponent` replaces each node entirely, here with a comment and a button to show its replies. The node spreads `treeItemProps` and renders `children`, so TreeSelect still manages which threads are open, and the thread can be navigated with the arrow keys.

</LiveExample>

This tree has no `valueProperty`, so it is display-only. See [Custom nodes](../customization.mdx#custom-nodes) for what a custom node should render.
