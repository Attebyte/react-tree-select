# Styling with Tailwind CSS

The default parts are restyled with class names. Classes that conflict with a default (such as the checkbox size) replace it, because class names are merged with [tailwind-merge](https://github.com/dcastil/tailwind-merge).

<LiveExample source={StylingExampleSource} title='StylingExample.tsx'>
  <StylingExample />
</LiveExample>

The checkbox is drawn with a `::after` pseudo-element, so `after:` variants (like `after:text-2xl`) size the check mark. See [Customization](../customization.mdx) for every styling prop.
