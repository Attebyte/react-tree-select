# Large tree

This controlled tree has 21,110 nodes: 10 roots, each with 10 children, 100 grandchildren and 2,000 leaves. Check `Item 1` to select its 2,000 leaves at once.

## Why it stays fast

- A selection change copies only the changed nodes and their ancestors. Every other node keeps its identity.
- Nodes are memoized, so unchanged nodes don't re-render, and collapsed branches aren't rendered at all.
- Expansion and focus state are tracked per node, so expanding one node doesn't re-render the others.

TreeSelect renders every node in an expanded branch. If you need to show tens of thousands of nodes expanded at the same time, consider virtualizing the list.
