## Basic props

This example combines a few behavior props on a tree where `Child 1` is disabled:

- `defaultExpanded`: every node starts expanded
- `chainedSelect={false}`: each node is selected individually
- `expandDisabledNodes={false}`: disabled nodes can't be expanded or collapsed

</LiveExample>

Because the nodes start expanded, the disabled `Child 1` stays expanded. With `chainedSelect` turned off, the children of a disabled node can still be selected, which is useful when selecting a parent isn't meaningful.
